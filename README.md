# Gestion_Enseignant_NodeJs
Une app web SPA avec backend Express.Js de NodeJs et frontend ave ReactJs permettant:
-d'ajouter des données dans une table Enseignant
-dafficher les données dans un tableau avec salaire
-de modifier et supprimer un enregistrement a partir d'un tbleau
-d'afficher un bilan : salaire min/max des enseignants avecle montant total des salaires
-de visualiser ce ilan dans un histogramme ou camembert 

Page d'authentification contenant 3 menus (ajout, listage et mise a jour, bilan et graphe)
Ajout - suppression - mise a jour ---> message (ajout/suppression/mise a jour reussie/echouée)
